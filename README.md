# What is EVO?

**EVO** is a modern, statically typed programming language designed to replace most application programming languages with **one consistent language**.

Write applications once and target:

* 🌐 Web
* ⚙️ Backend
* 📱 Mobile
* 🖥 Desktop
* ☁️ Cloud
* 🧠 AI Applications
* 🎮 Games
* 🔧 CLI Tools
* 📦 Microservices

while interoperating with existing ecosystems like C, C++, Rust, WebAssembly, JVM, and .NET when needed.

---

# Why EVO?

EVO is built around a simple philosophy:

> **One language. One syntax. Every application domain.**

Instead of learning different languages for different platforms, developers learn **one language** and reuse the same knowledge everywhere.

* Simplicity over complexity
* Consistency over cleverness
* Safety by default

# Features

* Modern, readable syntax
* Strong static type system
* Ownership and memory safety
* Fast native compilation
* Async concurrency
* Pattern matching
* Generics
* Traits
* Excellent diagnostics
* Incremental compilation
* Cross-platform
* LLVM + Native + WebAssembly backends (planned)
* AI semantic API
* Official formatter, linter, debugger and profiler
